# St. Bernard E-Procurement and Budgeting System

The **St. Bernard E-Procurement and Budgeting System** is an institutional web application engineered for streamlined procurement tracking, budget allocation, and data analytics. 

> **Powered By:** [TailAdmin React](https://tailadmin.com) – A free and open-source admin dashboard template built on **React and Tailwind CSS**.

![System Preview](./banner.png)

## Overview

The St. Bernard E-Procurement and Budgeting System leverages TailAdmin's essential UI components and responsive layouts to manage institutional procurement cycles, requisition monitoring, and budget distribution. 

### Core Tech Stack

- **Frontend Framework:** React 19
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Database & Analytics Integration:** MySQL & Python / Data Analytics
