# St. Bernard E-Procurement and Budgeting System

The **St. Bernard E-Procurement and Budgeting System** is an institutional web application engineered for streamlined procurement tracking, budget allocation, and data analytics. 

> **Powered By:** [TailAdmin React](https://tailadmin.com) – A free and open-source admin dashboard template built on **React and Tailwind CSS**.

![System Preview](./banner.png)

## Overview

The St. Bernard E-Procurement and Budgeting System leverages TailAdmin's essential UI components and responsive layouts to manage institutional procurement cycles, requisition monitoring, and budget distribution. 

### Core Tech Stack

- **Frontend Framework:** React 19
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Database & Analytics Integration:** MySQL & Python / Data Analytics

## Installation & Setup

### Prerequisites

Ensure you have the following installed on your environment:

- Node.js 18.x or later (Node.js 20.x or later recommended)

### Setup Steps

1. **Clone the project repository:**
   ```bash
   git clone [https://github.com/Little-Vampire-in-White/StBernardProcurementSystem.git](https://github.com/Little-Vampire-in-White/StBernardProcurementSystem.git)

```

2. **Install dependencies:**
```bash
npm install
# or
yarn install

```


3. **Launch the development server:**
```bash
npm run dev
# or
yarn dev

```

## Key Modules & Features

Utilizing the pre-designed, accessible React components provided by TailAdmin, the platform includes:

* **Procurement & Budget Dashboards:** Real-time visual metrics for department allocations and purchase approvals.
* **Requisition Management:** Input forms, authentication controls, and status tracking for purchase requests.
* **Data Analytics & Reports:** Interactive line and bar charts (powered by ApexCharts) for expenditure trends and budget forecasting.
* **User Role Management:** Profile settings, secure authentication, and modal approvals for administrative officers.
* **Data Tables:** Advanced tables equipped with sorting and filtering for procurement records and supplier data.
* **Dark Mode Support 🕶️:** Full theme customization for seamless usability.
